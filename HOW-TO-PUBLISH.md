# Publishing on GitHub (one time)

1. Make a free account at github.com.
2. Install GitHub Desktop from desktop.github.com and sign in.
3. In GitHub Desktop: File > Add local repository > pick this folder.
   If it says it is not a repository, click "create a repository here". Create it.
4. Click "Commit to main", then "Publish repository". Leave "Keep this code private" UNCHECKED
   so other people can download the app.
5. On github.com open your repository > Releases > "Create a new release".
   Click "Choose a tag", type v1.0.0, click "Create new tag", then "Publish release".
6. Click the Actions tab. A build starts and takes about 5-10 minutes.
   When it finishes, the installer appears on the release page.

To update later: change the files, commit and push in GitHub Desktop, then make a new release with a new tag (v1.0.1).
